=== Люди и Верблюды — Подопечные ===
Contributors: bfcamel
Stable tag: 1.0.1
Requires at least: 6.0
Requires PHP: 7.4

Единый плагин для четырёх прежних WPCode-сниппетов:
- База подопечных;
- Страница подопечных;
- Подопечные на главной;
- Другие истории.

== Совместимость ==

Плагин сохраняет без изменений:
- post type: lv_ward;
- taxonomy: lv_ward_type;
- все meta keys (_lv_ward_*);
- shortcode [lv_wards_page];
- shortcode [lv_wards_home];
- публичные функции lv_get_ward_data(), lv_get_wards(), lv_get_ward_image(), lv_get_ward_history_url() и остальные legacy-функции;
- HTML-классы и CSS-селекторы существующих блоков;
- логику пагинации, карусели, статуса умерших и блока «Другие истории».

== Шрифты ==

Плагин намеренно НЕ задаёт font-family и не подключает веб-шрифты.
Все размеры, веса, интервалы, цвета, отступы, адаптив и остальные стили исходных сниппетов сохранены.
Шрифтовая гарнитура наследуется от отдельного глобального сниппета/темы сайта.

== Переход со старых сниппетов ==

1. Загрузите и активируйте плагин.
2. Если старые WPCode-сниппеты ещё активны, плагин покажет предупреждение и не будет дублировать их модули.
3. Отключите четыре старых сниппета.
4. Обновите любую страницу или админку — плагин автоматически начнёт обслуживать те же CPT, данные, шорткоды и стили.

Удалять или переносить записи lv_ward не требуется.


== Изменения 1.0.1 ==

- Исправлена синхронизация адаптива карусели: JavaScript больше не дублирует CSS-breakpoints и определяет 3/2/1 карточку по фактической ширине.
- ResizeObserver теперь выполняет полный пересчёт карусели, включая точки, стрелки и допустимый индекс.
- Невидимые карточки карусели помечаются aria-hidden и inert в поддерживающих браузерах, чтобы клавиатурный фокус не уходил за пределы viewport.
- Блок «Другие истории» теперь формируется только на страницах, реально связанных с опубликованным подопечным, а не на всём frontend.
- URL каталога централизован: сначала используется опубликованная /wards/, затем для обратной совместимости /home/wards/, после чего fallback /wards/.
- Шрифты по-прежнему не задаются и не подключаются плагином.
