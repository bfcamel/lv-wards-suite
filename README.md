# Люди и Верблюды — Подопечные

WordPress-плагин фонда «Люди и Верблюды» для единой базы подопечных и её отображения на сайте.

**Текущая версия: 1.0.1**

## Возможности

- база подопечных на CPT `lv_ward`;
- типы подопечных через taxonomy `lv_ward_type`;
- дата рождения и автоматический расчёт возраста;
- статус «Умер» и дата смерти;
- два текстовых блока;
- фотография из Media Library;
- связь с существующей страницей истории WordPress;
- ручной порядок подопечных;
- каталог подопечных с серверной пагинацией;
- динамическая карусель подопечных на главной;
- блок «Другие истории» со случайными подопечными;
- сохранение обратной совместимости с прежними WPCode-сниппетами.

## Шорткоды

```text
[lv_wards_page]
[lv_wards_home]
```

## Публичный API

Сохраняются legacy-функции, включая:

```php
lv_get_ward_data();
lv_get_wards();
lv_get_ward_image();
lv_get_ward_history_url();
```

## Совместимость

Плагин сохраняет существующие:

- post type `lv_ward`;
- taxonomy `lv_ward_type`;
- meta keys `_lv_ward_*`;
- шорткоды;
- HTML-классы и CSS-селекторы;
- логику каталога, карусели, страниц памяти и блока «Другие истории».

При наличии старых активных WPCode-сниппетов соответствующий модуль плагина не загружается, а администратору показывается предупреждение. После отключения старого сниппета плагин автоматически берёт его функции на себя.

## Шрифты

Плагин намеренно не задаёт `font-family` и не подключает веб-шрифты. Гарнитура наследуется от глобальных стилей сайта.

## Требования

- WordPress 6.0+
- PHP 7.4+

## Версия 1.0.1

- исправлена синхронизация адаптива карусели;
- `ResizeObserver` выполняет полный пересчёт карусели;
- невидимые карточки исключены из клавиатурной навигации;
- «Другие истории» загружаются только на связанных страницах подопечных;
- URL каталога централизован с поддержкой `/wards/` и legacy `/home/wards/`;
- шрифты по-прежнему не задаются плагином.

## Установка

1. Скопируйте каталог плагина в `wp-content/plugins/lv-wards-suite/`.
2. Активируйте «Люди и Верблюды — Подопечные» в WordPress.
3. Если используются прежние WPCode-сниппеты, после проверки отключите их.
